# sigmund-translator
sigmund translator is a language assistant made to convert large blocks of text to layman's terms. created for the Veritas AI hackathon 2026.
sigmund translator is a language assistant designed to make communication easier whether it may be converting official documents to layman's language,
or just simplifiying huge blocks of text to one that a fourth grader could understand, sigmunds got your back.
